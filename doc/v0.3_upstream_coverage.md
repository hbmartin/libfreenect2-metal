## Release-only hardware evidence

Before publishing `v0.3.0`, attach results for the available Kinect lifecycle
soak, 60-second raw recording/replay validation, Intel or AMD VAAPI runtime
fallback run, CPU/CUDA recording parity, and three-distance plus unseen
holdout calibration. Hosted CI intentionally does not report GPU or USB
runtime success when it only compiled or simulated those paths.
